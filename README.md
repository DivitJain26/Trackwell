# TrackWell — AI-Based At-Risk Student Identification & Early Intervention Platform

TrackWell is a locally runnable web application that helps faculty identify students who may be
academically at risk before final examinations. It collects academic and behavioural indicators,
predicts a **Low / Medium / High** risk category with a scikit-learn model, explains the main
contributing factors, raises alerts, and lets faculty record and follow up interventions.

Everything runs on a normal laptop: Flask + SQLite + scikit-learn, no cloud services, no paid
APIs, no Docker. Internet access is needed only once, to install the Python packages.

> **About the data:** the bundled datasets (`data/training_data.csv`, `data/sample_students.csv`)
> are **synthetic**, generated by `scripts/generate_training_data.py` and `scripts/make_sample_data.py`.
> They do not describe real students. Model metrics obtained on them show that the pipeline works;
> they are not evidence of real-world predictive performance.

## 1. Requirements

- **Python 3.10 or newer** (tested with 3.12–3.14). On Windows, download from
  <https://www.python.org/downloads/> and tick **"Add python.exe to PATH"** during installation.
- About 500 MB of free disk space for the virtual environment.
- A modern browser (Edge, Chrome, Firefox).

## 2. Quick start on Windows

1. Open the project folder (the one containing `run.bat`) in File Explorer.
2. Double-click **`run.bat`** (or open *Command Prompt* in the folder and type `run.bat`).
   The script:
   - creates a virtual environment in `.venv` (first run only),
   - installs the pinned dependencies from `requirements.txt` (first run only),
   - initialises the SQLite database in `instance\trackwell.db`,
   - starts the server at **http://127.0.0.1:5000**.
3. Open <http://127.0.0.1:5000> in your browser.
4. **Create the administrator account.** While no administrator exists, the login page shows a
   link *"Create the first administrator account"*. Fill in a name, username and a password
   (minimum 8 characters including a digit or symbol). This form disappears permanently once an
   administrator account exists.
5. Sign in as the administrator.
6. **Train the model:** go to *Model status* → *Train & evaluate* (about 20 seconds), or run
   `python scripts\train_model.py` in a second terminal (see §4).
7. **Add students:** *Student management → Add student*, or *CSV import* and upload
   `data\sample_students.csv` (synthetic demo records).
8. **Generate predictions:** *Risk predictions → Run active model*.

Press `Ctrl+C` in the terminal window to stop the server. Your data stays in `instance\trackwell.db`.

### Same steps typed manually (Windows Command Prompt)

```bat
cd path\to\trackwell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python scripts\init_db.py
python scripts\create_admin.py
python scripts\train_model.py

```

Then open <http://127.0.0.1:5000>.

## 4. Command reference

Run these from the project folder with the virtual environment activated
(`.venv\Scripts\activate` on Windows, `source .venv/bin/activate` elsewhere).

| Task | Command |
|---|---|
| Initialise / upgrade the database (safe to re-run, keeps data) | `python scripts/init_db.py` |
| Create the first administrator interactively | `python scripts/create_admin.py` |
| Train, evaluate and activate a new model version | `python scripts/train_model.py` |
| Load the synthetic demo students + demo accounts | `python scripts/seed_demo.py` |
| Regenerate the synthetic training dataset | `python scripts/generate_training_data.py` |
| Regenerate the synthetic sample students | `python scripts/make_sample_data.py` |
| Back up the database to `instance/backups/` | `python scripts/backup_db.py` |
| Start the application | `python app.py` |
| Run the automated tests | `python -m pytest` |

## 5. Demo accounts (optional, demo-only)

`python scripts/seed_demo.py` imports `data/sample_students.csv`, adds assessment history, and
creates these **demo-only** accounts. Each has a temporary password and is forced to set a new
one at first login. Do not use them outside a demonstration.

| Role | Username | Temporary password |
|---|---|---|
| Faculty | `faculty.demo` | `Faculty@2026` |
| Student (linked to CSE22001) | `student.demo` | `Student@2026` |

The script never creates an admin account; create that through the setup page or
`scripts/create_admin.py` so the password is never written down in the repository.

## 6. Where things are stored

| Item | Location |
|---|---|
| SQLite database | `instance/trackwell.db` |
| Trained model artifacts (versioned, checksummed) | `instance/models/model_vN.joblib` |
| Local log file | `instance/logs/trackwell.log` |
| Pending CSV imports | `instance/uploads/` |
| Session secret key (auto-generated) | `instance/secret_key` |
| Synthetic training data | `data/training_data.csv` |
| Synthetic demo students / assessments | `data/sample_students.csv`, `data/sample_assessments.csv` |

**Backup:** stop the app and copy the `instance` folder, or run `python scripts/backup_db.py`.
**Reset:** stop the app and delete `instance/trackwell.db`. The schema is recreated at the next
start and the first-run setup page appears again. **Restarting** the app never deletes data.

## 7. Configuration

Copy `.env.example` to `.env` to override defaults (host, port, instance path, secret key).
All values are optional. The secret key is generated once and stored in `instance/secret_key`
if `TRACKWELL_SECRET_KEY` is not set, so sessions survive restarts without a hardcoded secret.

## 8. Features

- **Authentication & roles** – local login, salted password hashes (Werkzeug scrypt), Flask
  sessions, server-side role checks (admin / faculty / student), forced password change for
  temporary passwords, first-run admin setup, CSRF protection on every form.
- **Student management** – add, edit, view, search, filter (class, semester, risk), delete with
  confirmation; unique student IDs; range validation shared by forms and CSV import.
- **CSV import / export** – template download, validation report (columns, types, ranges,
  missing values, duplicates, existing IDs) with preview before anything is written; skip or
  update existing records; export filtered students and predictions.
- **Assessment history** – per-student quiz/test scores feeding a score-trend feature.
- **Preprocessing pipeline** – one shared feature-engineering function, imputation, scaling,
  one-hot encoding inside a scikit-learn `Pipeline`, fitted on training data only; leakage
  columns (`final_exam_pct`, `risk_label`) excluded from inputs.
- **Model training & evaluation** – Logistic Regression vs Random Forest vs Gradient Boosting,
  stratified cross-validation plus a 20 % held-out split; accuracy, precision, recall, F1,
  per-class report and confusion matrix; selection by `0.5·macroF1 + 0.5·recall(High)`.
- **Predictions & explanations** – class probabilities, argmax category, 0–100 risk score,
  model-derived local factors (reference substitution), global feature importance, and clearly
  separated rule-based observations.
- **Faculty dashboard** – live counts, risk distribution, attendance bands, risk by class,
  highest-risk students, new alerts, intervention summary; empty states throughout.
- **Alerts** – raised for new High Risk and risk increases, de-duplicated, mark-as-reviewed,
  link to an intervention.
- **Interventions** – type, date, notes, responsible faculty, follow-up date, status, outcome;
  status and overdue filters; history on the student profile.
- **Student dashboard** – own indicators only, observations, suggested actions, optional risk
  indicator (admin setting); faculty notes are never exposed.
- **Model management** – versioned artifacts with metadata and SHA-256 checksums; status page;
  activate earlier versions; refuses to load untrusted artifacts.
- **Admin** – user management, settings (reference levels, student visibility), audit log.

## 10. Troubleshooting

- **`python` is not recognised** – reinstall Python with "Add to PATH", or use `py` instead of
  `python` on Windows.
- **`ModuleNotFoundError`** – the virtual environment is not active or dependencies were not
  installed: run `.venv\Scripts\activate` then `pip install -r requirements.txt`.
- **Port 5000 already in use** – set `TRACKWELL_PORT=5001` in `.env` and restart.
- **"No trained model is active"** – train one from the *Model status* page or with
  `python scripts/train_model.py`.
- **Forgot the admin password** – another admin can reset it under *User management*. If no admin
  can log in, back up and delete `instance/trackwell.db` to start over.
- Unexpected errors show a generic page; details are written to `instance/logs/trackwell.log`.

## 11. Limitations

- Training data is synthetic; real labelled data must be supplied (same columns) to make any
  claim about predictive performance.
- Probabilities are not calibrated; risk categories are argmax of class probabilities.
- Model-derived explanations use reference substitution rather than SHAP (SHAP is not a
  dependency to keep installation reliable).
- The built-in Flask development server is intended for local single-user or small-group use,
  not for public deployment.
